# ILogger

**定位：語言無關 × 專案無關**

本文件定義系統事件日誌寫入與查詢介面。

依賴：引用 Logging/LogEntry、Logging/LogLevel、Common/Timestamp

---

## 方法

| 方法名稱 | 輸入 | 回傳 | 說明 |
|---------|------|------|------|
| `Debug` | 訊息（字串）、來源元件（字串 或 空值） | 布林 | 寫入一筆 `Debug` 層級的日誌；回傳是否寫入成功 |
| `Info` | 訊息（字串）、來源元件（字串 或 空值） | 布林 | 寫入一筆 `Info` 層級的日誌；回傳是否寫入成功 |
| `Warning` | 訊息（字串）、來源元件（字串 或 空值） | 布林 | 寫入一筆 `Warning` 層級的日誌；回傳是否寫入成功 |
| `Error` | 訊息（字串）、例外資訊（字串 或 空值）、來源元件（字串 或 空值） | 布林 | 寫入一筆 `Error` 層級的日誌；例外資訊 MUST 對應至 `LogEntry.ExceptionInfo`；回傳是否寫入成功 |
| `Query` | 層級篩選（`LogLevel` 或 空值）、起始時間（時間戳記 或 空值）、結束時間（時間戳記 或 空值）、關鍵字（字串 或 空值） | `LogEntry` 列表 | 查詢日誌條目；層級篩選為空值時回傳所有層級；關鍵字為空值時不篩選訊息內文 |

## 約束

- 每筆日誌 MUST 自動附加寫入時刻的時間戳記，格式見 Common/Timestamp
- `Query` 回傳結果 MUST 依時間戳記遞減排序（最新在前）
- `Query` 的起始時間與結束時間同時有值時，起始時間 MUST NOT 晚於結束時間
- `Query` 的時間範圍篩選採閉區間語意（含頭含尾）：起始時間若有值，時間戳記等於起始時間的條目 MUST 被納入結果；結束時間若有值，時間戳記等於結束時間的條目 MUST 被納入結果
- `Query` 的關鍵字若有值，MUST NOT 為空字串；關鍵字比對範圍為 `LogEntry.Message`
- 日誌寫入失敗時 MUST 以回傳值 `false` 通知呼叫端；MUST NOT 中斷呼叫端的執行路徑；是否中斷主流程由呼叫端自行決定
- 日誌寫入方法回傳 `false` 時，僅表示該筆日誌未成功寫入；本介面不提供失敗原因分類
- `Query` 的底層來源不可用或無法讀取時，MUST 回傳空列表，MUST NOT 中斷呼叫端執行路徑
