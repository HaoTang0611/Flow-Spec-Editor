# InspectionPipelineConfiguration

**定位：語言無關 × 專案無關**

本文件定義單一檢測流程識別資料模型，用於描述可被外部組合規則引用的命名流程。

---

## 欄位

| 欄位名稱 | 型別 | 說明 |
|---------|------|------|
| `Name` | 字串 | 流程名稱，供使用者識別（例：正面外觀檢查） |

## 約束

- `Name` MUST NOT 為空字串
- Core Contract 不規定一個檢測流程包含幾個相機、幾個前處理步驟、幾個模型，也不規定其排序、分支或對應關係
- 相機、前處理與模型之間的完整組合規則 MUST 由外部定義
- 外部定義的檢測流程 MUST 保證引用的相機、前處理步驟與模型設定可解析為本契約定義的合法資料結構
- 外部定義來源與機制不在 Core Contract 的規範範圍內
