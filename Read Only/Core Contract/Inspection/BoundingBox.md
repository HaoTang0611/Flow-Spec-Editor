# BoundingBox

**定位：語言無關 × 專案無關**

本文件定義缺陷位置的矩形邊界框資料模型，以像素座標描述缺陷在影像中的範圍。

---

## 欄位

| 欄位名稱 | 型別 | 說明 |
|---------|------|------|
| `X` | 整數 | 邊界框左上角 X 座標（像素），原點為影像左上角 |
| `Y` | 整數 | 邊界框左上角 Y 座標（像素），原點為影像左上角 |
| `Width` | 整數 | 邊界框寬度（像素） |
| `Height` | 整數 | 邊界框高度（像素） |

## 約束

- `X` MUST 大於等於 0
- `Y` MUST 大於等於 0
- `Width` MUST 大於 0
- `Height` MUST 大於 0
