# PreprocessingStepType

**定位：語言無關 × 專案無關**

本文件定義影像前處理步驟類型枚舉，供 `IImagePreprocessor.Configure` 的步驟列表使用。

---

## 枚舉值

| 值 | 說明 |
|----|------|
| `PatternMatch` | 模板比對，在指定搜尋區域內定位 Pattern，並將影像對齊至 Pattern 座標系 |
| `ROICrop` | 感興趣區域裁切，擷取指定矩形範圍（含旋轉）的子影像 |

---

## PatternMatch 參數規格

輸出語意：輸出影像為依 Pattern 空間對齊後的影像，尺寸與輸入影像一致。

| 參數鍵 | 型別（以字串表示） | 必要 | 合法值範圍 | 說明 |
|--------|--------------|:----:|-----------|------|
| `TemplateId` | 字串 | 是 | 非空字串 | Pattern 影像識別碼，參照平台維護的範本庫 |
| `X` | 整數 | 是 | ≥ 0 | 搜尋區域起點水平座標（像素，由左計） |
| `Y` | 整數 | 是 | ≥ 0 | 搜尋區域起點垂直座標（像素，由上計） |
| `Width` | 整數 | 是 | > 0 | 搜尋區域寬度（像素） |
| `Height` | 整數 | 是 | > 0 | 搜尋區域高度（像素） |
| `Angle` | 小數 | 是 | -180.0 到 180.0（含兩端） | 允許搜尋的旋轉角度範圍（度），以 0° 為基準的對稱容差 |

約束：`X + Width` MUST ≤ 輸入影像寬度；`Y + Height` MUST ≤ 輸入影像高度。

---

## ROICrop 參數規格

輸出語意：輸出為以裁切區域中心點為旋轉中心、旋轉 `Angle` 後裁切出的 `Width × Height` 像素子影像。

| 參數鍵 | 型別（以字串表示） | 必要 | 合法值範圍 | 說明 |
|--------|--------------|:----:|-----------|------|
| `X` | 整數 | 是 | ≥ 0 | 裁切起點水平座標（像素，由左計） |
| `Y` | 整數 | 是 | ≥ 0 | 裁切起點垂直座標（像素，由上計） |
| `Width` | 整數 | 是 | > 0 | 裁切寬度（像素） |
| `Height` | 整數 | 是 | > 0 | 裁切高度（像素） |
| `Angle` | 小數 | 是 | -180.0 到 180.0（含兩端） | 裁切區域旋轉角度（度，順時針為正），旋轉中心為裁切區域中心點 |

約束：旋轉後裁切範圍 MUST 完全落在輸入影像邊界內；超出邊界時 MUST 視為無效配置。
